# Utility Libraries

This directory contains common utility functions and helper libraries that are used by both the VFD (Virtual File Driver) and VOL (Virtual Object Layer) trackers.

## Subdirectories

- **`debug/`**: Contains utilities for debugging, tracing, and timing. These tools help in performance analysis and in understanding the behavior of the trackers.
- **`md5/`**: Provides functions for MD5 hash computation. This can be used for data integrity checks and other purposes.
- **`uthash/`**: Includes the `uthash` library, a hash table implementation for C structures.

# MD5 Hash Computation

This directory contains a public-domain implementation of the MD5 message-digest algorithm. It is used for computing MD5 hashes of data, which can be useful for data integrity checks and other purposes.

## Files

- **`md5.c`**: The source code for the MD5 implementation.
- **`md5.h`**: The header file for the MD5 implementation.

This implementation is based on the public domain source code by Alexander Peslyak (Solar Designer).

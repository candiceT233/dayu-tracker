# Analysis Utility Scripts

This directory contains a collection of Python scripts that provide reusable functions for the analysis notebooks in the parent directory. These scripts are designed to simplify the process of loading, processing, and visualizing the data collected by DaYu-Tracker.

## Scripts

- **`stat_loader.py`**: A set of utility functions for loading and processing the JSON statistics files generated by DaYu-Tracker. It includes functions for finding files, loading JSON data, and creating task-file mappings.

- **`stat_print.py`**: Provides functions for printing and formatting various statistics, such as overhead and I/O stats.

- **`vol_stat2graph.py`**: Contains functions for converting VOL (Virtual Object Layer) statistics into a NetworkX graph, which can then be used for further analysis and visualization.

- **`vfd_stat2graph.py`**: Contains functions for converting VFD (Virtual File Driver) statistics into a NetworkX graph.

- **`vol_graph2sankey.py`**: Provides functions for converting a VOL-based NetworkX graph into a Sankey diagram using Plotly.

- **`vfd_graph2sankey.py`**: Provides functions for converting a VFD-based NetworkX graph into a Sankey diagram using Plotly.

- **`full_stat2graph.py`**: A script for combined VOL and VFD analysis, allowing for the creation of a single graph that represents both levels of I/O activity.

- **`dependency_parser.py`**: A placeholder for a script that will parse data dependencies.

- **`prefetch_shema_parser.py`**: A placeholder for a script that will parse prefetching schemas.

- **`show_workflow_io_stat.py`**: A script for displaying I/O statistics for a workflow.

# DaYu-Tracker Flow Analysis

This directory contains a suite of powerful analysis and visualization tools for the data collected by DaYu-Tracker. These tools allow you to transform raw tracking data into interactive visualizations, performance metrics, and insightful workflow diagrams.

## Key Capabilities

- **Interactive Sankey Diagrams**: Visualize the data flow between tasks, datasets, and files.
- **Performance Analysis**: Analyze tracking overhead and identify performance bottlenecks.
- **Workflow Visualization**: Generate graph-based representations of HDF5 operations.
- **Statistical Analysis**: Examine I/O patterns and access statistics.

## Analysis Notebooks

The Jupyter notebooks in this directory provide a variety of analysis and visualization capabilities:

- **`VOL_stat_to_Sankey.ipynb`**: Generates Sankey diagrams from VOL (Virtual Object Layer) tracking data, showing object-level data flow.
- **`VFD_simple_stat_to_Sankey.ipynb`**: Generates Sankey diagrams from VFD (Virtual File Driver) tracking data, showing file-level I/O operations.
- **`Full_stat_to_Sankey.ipynb`**: Combines VOL and VFD analysis for a comprehensive data flow visualization.
- **`Overhead_Analysis.ipynb`**: Analyzes the performance overhead of the DaYu-Tracker.
- **`detailed_VOLVFD_Graph_SimAgg.ipynb`**: Provides detailed graph analysis with similarity aggregation.
- **`grouped_VOLVFD_Graph_SimAgg.ipynb`**: Offers grouped analysis with similarity aggregation.
- **`io_vol_vfd.ipynb`**: Analyzes I/O patterns across both the VOL and VFD layers.

## Utility Scripts (`utils/`)

The `utils/` directory contains a collection of Python scripts that provide reusable functions for the analysis notebooks:

- **`stat_loader.py`**: Utilities for loading and processing the JSON statistics files generated by DaYu-Tracker.
- **`stat_print.py`**: Functions for printing and formatting statistics.
- **`vol_stat2graph.py` / `vfd_stat2graph.py`**: Scripts for converting VOL and VFD statistics into NetworkX graphs.
- **`vol_graph2sankey.py` / `vfd_graph2sankey.py`**: Scripts for converting NetworkX graphs into Sankey diagrams.
- **`full_stat2graph.py`**: For combined VOL and VFD analysis.

## Getting Started

1.  **Install Dependencies**:

    ```bash
    pip install -r requirements.yaml
    ```

2.  **Run a Notebook**:

    Launch Jupyter Notebook and open one of the analysis notebooks to get started.

    ```bash
    jupyter notebook
    ```

## Example Statistics

The `example_stat/` directory contains example statistics from various scientific workflows. These can be used to test the analysis tools and to see examples of the kinds of insights that can be gained from DaYu-Tracker.

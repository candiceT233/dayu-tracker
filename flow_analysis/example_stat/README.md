# Example Statistics

This directory contains example statistics from various scientific workflows that have been analyzed with DaYu-Tracker. These examples can be used to test the analysis tools and to see the kinds of insights that can be gained from this tool.

## Workflows

- **`ddmd/`**: DeepDriveMD, a molecular dynamics workflow.
- **`s9f9p8/`**: PyFlexTRKR, a parallel weather tracking workflow.
- **`seq9f9s/`**: A sequential version of the PyFlexTRKR workflow.
- **`sync-write-1d-contig-contig-read-full_1/`**: A synthetic benchmark that performs synchronous writes and reads.
- **`vist/`**: The VisIt visualization tool.
- **`vist_1t_chunk/`**: A version of the VisIt workflow with chunked data.

## Contents

Each subdirectory contains the following:

- **`.json` files**: The raw statistics files generated by the DaYu-Tracker VFD and VOL trackers.
- **`.html` files**: Interactive Sankey diagrams and other visualizations generated by the analysis notebooks.
- **`.png` files**: Static images of the workflow graphs.

## Viewing the Reports

To view the interactive HTML reports, you can open them in your web browser. The PNG images can be viewed with any image viewer.

These examples demonstrate the power of DaYu-Tracker to reveal the complex I/O patterns of real-world scientific applications.
